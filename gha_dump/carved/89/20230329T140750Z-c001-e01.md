Titanfall 2 has `A` & `B` lightmaps for both `SKY` & `RTL`

If the `RTL` lump is internal, the engine expects "9 bytes per texel" & will throw an error
We've tried to extract the 1/4 size `RTL` `C` lightmap, but it appears to always be white (dummy data?)

All lightmaps are still `RGBA32`

`SKY` `A` & `B` seem to work the same as in Titanfall
`RTL` `A` appears to be a mask (all white, holes punched in alpha)
`RTL` `B` looks to be light indices encoded as colour (variable names decompiled from shaders seem to confirm this)

## Sample
```python
>>> import bsp_tool
>>> from bsp_tool.extensions import lightmaps
>>> lightmaps.save_rbsp_r2(bsp_tool.load_bsp("E:/Mod/Titanfall2/maps/mp_colony02.bsp"))
```
> NOTE: `save_rbsp_r2` generates `.json` for splitting up panels & writing back changes to the exported images
