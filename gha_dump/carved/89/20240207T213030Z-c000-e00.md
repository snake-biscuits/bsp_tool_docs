# Titanfall
For each `LIGHTMAP_HEADER` Titanfall produces 2 `SKY` lightmaps & 1 `RTL`
All pixels are `RGBA32`

`SKY` `B` lightmaps look like a normal map
Unsure if this is used for global illumination or shadows (bounce along axis vs. block along axis)

`RTL` seems to only be shades of grey & blue, we'll get deeper into `RTL` theory with Titanfall 2

> NOTE: samples extract each lightmap the stitch them into panels

## Sample
```python
>>> import bsp_tool
>>> from bsp_tool.extensions import lightmaps
>>> lightmaps.save_rbsp_r1(bsp_tool.load_bsp("E:/Mod/Titanfall/maps/mp_colony.bsp"))
```
