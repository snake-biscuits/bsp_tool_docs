# Apex Legends
Apex Legends lightmaps aren't as well mapped atm

Once again, `RTL` has changed (5 bytes-per-texel)
`RTL` is also much harder to see, and with current performance, it's difficult to test multiple samples
At present I'm extracting 1x `RGBA32` @ 1/1 size & 1x `RGBA32` @ 1/4 size

Season 3's lobby probably isn't the best example, but I don't want to push GitHub's upload limits
Feel free to try out other maps w/ `extensions.lightmaps`
You'll need to install Pillow w/ pip (or `pip install bsp_tool[extended]`)
The `from bsp_tool.extensions import lightmaps` syntax is important: `import bsp_tool.extensions` will not load any extensions!
> this is so you don't get any errors using `bsp_tool` without installing any dependencies

## Sample
```python
>>> import bsp_tool
>>> from bsp_tool.extensions import lightmaps
>>> lightmaps.save_rbsp_r5(bsp_tool.load_bsp("E:/Mod/ApexLegends/season3/3dec19/maps/mp_lobby.bsp"))
```
