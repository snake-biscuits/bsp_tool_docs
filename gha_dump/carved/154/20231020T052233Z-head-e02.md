## Requirements
### Steam
 * Half-Life 2
   - Source SDK
 * Dino D-Day
   - Dino D-Day SDK

### Xbox 360
 * A copy of The Orange Box
 * Modded Console

### Xenia (Xbox 360 Emulator)
 * Xenia Canary
   - Game Patches
 * https://github.com/XboxDev/extract-xiso
   only needed if you used the redump.org ripping method[^rd]



## Tools Setup
### Hammer
 * VDC: [SDK Installation](https://developer.valvesoftware.com/wiki/SDK_Installation)
> NOTE: Any Hammer should do, the import thing is that we target the compilers in `half-life 2/bin/`


### `makegamedata.exe`
 * Install Dino D-Day & Dino D-Day SDK via Steam
 * Copy `bin/makegamedata.exe` to `<MyModTools>/game/ddd_mgd/bin/`
   Where `<MyModTools>/` is wherever you want to keep your tools / converted maps
   - also these `.dll`s:
```
bsppack.dll
FileSystem_Stdio.dll
mdllib.dll
Steam.dll
tier0.dll
vphysics.dll
vstdlib.dll
```
 * Create a `dinodday/` folder next to `bin/`
> NOTE: I haven't tested game folders besides `dinodday/`; other names might work


### Xenia Canary
 * Xenia Project Wiki: [Quickstart](https://github.com/xenia-project/xenia/wiki/Quickstart)
   - Xenia Project Wiki: Quickstart: [How to rip games](https://github.com/xenia-project/xenia/wiki/Quickstart#how-to-rip-games)
 * xenia-canary/game-patches: [Installing Patches](https://github.com/xenia-canary/game-patches#installingupdating)

Change the following lines in `xenia-canary.config.toml`[^xc]:
```toml
# safety net
break_on_unimplemented_instructions = false
# console commands
# "-dvd" helps the game run
# "-game hl2 +map credits" sets the map to Half-Life 2's credits
cl = "-dvd -game hl2 +map credits"
# text rendering
d3d12_readback_memexport = true
d3d12_readback_resolve = true
```
> NOTE: we will later change `-game` & `+map` to your map
> NOTE: I have yet to launch maps with `-game tf`[^xc]


## Xbox360 Files
If you used the Redump ripping method[^rd] your copy of The Orange Box will be in an `.iso`
You can use `extract-xiso` to break up the files for modding
 * Download the latest build of
 * Extract the `.iso` 
> NOTE: porting files back to Xbox360 hardware is outside the scope of this guide; try the X360 Source Engine Discord
 * Copy the extracted disc image to `<360Files>/`
   Where `<360Files>/` is wherever you keep your Xbox360 disk images

## Troubleshooting
### Xenia Controls
I'd recommend using a controller w/ Xenia
Keyboard controls are available:
![xenia_keyboard_controls](https://github.com/snake-biscuits/bsp_tool/assets/36507175/b69eb337-4d8a-44e9-b22a-cdf5f29679e5)
Bindings can only be changed by editing `xenia-canary.config.toml`
### Baseline Test
Make sure to run `<360Files>/default.xex` w/ Xenia targeting an official map first[^mr]
```toml
cl = "-dvd -game hl2 +map d1_trainstation_01"
```
If that runs OK you'll know for sure that your map is the problem

### Xenia isn't working
 * Can your system specs handle Xenia?
 * Is the latest version of Xenia broken?
 * Double-check `xenia-canary.config.toml`
 * Check the Xenia bug reports for The Orange Box[^cl]
   Someone else might've encountered the same issue

## Compiling
 * Make & compile a map with Hammer
 * Run around on PC to make sure the map works ok
 * Copy the `.bsp` from your working folder (or `half-life2/hl2/maps` to `<MyModTools>/game/ddd_mgd/dinodday/`
 > NOTE: you can skip this step if you keep the `.vmf` in `<MyModTools>/game/ddd_mgd/dinodday/`
 * Open a terminal in `<MyModTools>/game/ddd_mgd/dinodday/`
   E.g. `Shift+Right Click` in the folder and select `Open PowerShell window here`
 * In the Terminal, run: `../bin/makegamedata.exe <mapname>.bsp`
   `makegamedata.exe` refuses to run unless run from inside a sub-directory of `game/`
 
 
 ## Running maps
 * Copy `<mapname>.360.bsp` to `<360Files>/<game>/maps/<mapname>.360.bsp`
 * Update the following line of the Xenia Config:
```toml
# change this line in xenia-canary.config.toml to play HL2's first map
cl = "-dvd -game <game> +map <mapname>"
```
 * Open `<360Files>/default.xex` in Xenia (Drag & Drop works too)
 * You should load directly into your map
> NOTE: Xenia will give you an error message
 

 ## Limitations
 * No Props
   Mounting assets from `<360Files>/hl2/zip0.360.zip` in `<MyModTools>/game/ddd_mgd/dinodday/` might help
 * Maps with pickups crash on load (including the HEV suit)
   I remember hearing something about the physics load of everything falling `OnMapSpawn` crashing dev Xbox360s
