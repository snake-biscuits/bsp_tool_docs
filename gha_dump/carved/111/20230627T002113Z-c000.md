Only ever seen up to leaf type 0-7. or well, child type 0-7

### Child Types
 0 - BVH4 node
 1 - no child
 2 - (unk, nullsub)
 3 - (unk, points to other leaves)
 4 - unpacked vert tri (bsp)
 5 - packed vert tri (rmdl)
 6 - unpacked vert quad (bsp)
 7 - packed vert quad (rmdl)

Only difference between 4-5 and 6-7 is that:
 - one uses packed vertices (int16 with a scale factor of sorts to scale it up to the right value)
 - one uses regular float3s

`bsp`s can technically use packed vertices tho i dont think any do
But while most `rmdl`s use packed vertices, i have seen some that don't

The decision to use packed/unpacked is based on the physical size of the model (i.e., how big it appears in the world)
If the coordinates are very large then they will lose meaningful levels of accuracy by being packed, so they must be raw floats
