Apex Legends throws out the `CM_*` & `TRICOLL_*` physics systems
Their replacement lives in `BVH_NODES` & `BVH_LEAF_DATA`
`rmdl` uses the same system as `bsp`, though they tend to use different parts of the format

A `BVHNode` can index into `BVHLeafData` & provide a type
Each type enum selects a handler function and feeds it some context + the pointer into `BVHLeafData`

`BVHLeafData` ends up being a combination of different data types all squished together
So far we have identified a few types, but not necessarily how they function, or how to replicate them.
