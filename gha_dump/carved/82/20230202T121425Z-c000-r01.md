Wolfenstein 3D might use a similar VIS system to DOOM, but more primitive.
I haven't checked.

Wolf3D is a raycaster, like DOOM, but all maps are on a square grid.
Maps in Wolf3D can contain a lot of elements, and a lot of Id Software's early reputation came from what they could squeeze out of old PCs.
But using BSP trees for visibility sorting pre-dates Wolf3D anyway.[^wiki_bsp_refs] (Wolf3D released early 1992)
Partitioning space to reduce rendering costs pre-dates John Carmack![^dtic_study] (John Carmack was born mid 1970)

The origin of the BSP format isn't really the focus of this project.
Duke Nukem Forever's leaked 1996 build uses a BSP format.
Halo uses a BSP format.

BSP is a system. Not even that, an approach to rendering a space as optimally as possible.
`BSP = BVH2`, do you know how many more numbers there are than 2?!?

> `RespawnBsp` technically uses BVH4 in places, bounding volume hierarchies are flexible things.
> Using a BVH2 tree of nodes to map a PVS is neither unique nor game-changing.

**TL;DR: DOOM is a useful example for trying to explain VIS as simply as possible, it's not the origin of BSP VIS**
