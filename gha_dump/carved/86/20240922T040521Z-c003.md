`GeoSetBounds` wraps the `TriColl` (568), while `PrimitiveBounds` (5999) is at a 45 degree angle
The triangular pocket this outlines is really tight, any ray test is highly unlikely to fail

`bsp_regen` is far lazier in it's approach, using an AABB for each level & wrapping the `GeoSetBounds` around it's child `PrimitiveBounds`

Idk what kind of algorithm respawn developed to get this combination of YOBBs to create such a tight hull, but it's very cool
When I first visualised the bounds I was confused by the `PrimitiveBounds` not being fully contained in `GeoSetBounds`

Also worth noting that `Tricoll` has it's own tree of `TricollNodes` to minimise the number of tests for a ray miss
