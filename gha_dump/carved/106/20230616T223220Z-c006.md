```c++
// processing
full_22_bits = (high_11_bits << 11) | low_11_bits;
bevelCount   = full_22_bits & 0x7F;  //  7 from the bottom
tricollIndex = full_22_bits >> 7;    // 15 from the top
v85 = a1->tricollPointer[tricollIndex];
```

So each bevel is a stream of `11-bit` numbers, starting with a `22-bit` header split into `15` & `7` bits
The `getBevelIndices` function apparently collects `bevelCount` `11-bit` indices into `TricollTriangles`
`v87` determines the `TricollNodes` index of the target triangle
IIRC the indices into TricollBevels start on `32-bit` boundaries
