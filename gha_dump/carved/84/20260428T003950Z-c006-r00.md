`CellAABBNodes` doesn't appear to be related to `CellBspNodes/Cells`
It's used for rendering via `ObjReferences` (renderable geo like `Meshes` & static props)
So you'd assume that it has something to do with VIS

But there isn't any sort of lump relationship (indices) between them as far as I've found
However, you could use `Planes` in the `CellBspNode` tree to cull `AABB`s for rendering
Or `Portals` to update a stencil buffer

At this point I don't know if they're directly related
But I can imagine some real-time rendering scenarios they'd be helpful in
