`CellBspNodes`  is a BSP tree (index 0 is the root node)
When `Node.plane` `-1`: `Node.child` is a "leaf" `Cell`

Otherwise, `CellBspNode[index+0]` or `index+1` is the next node
If we want to be "in front" of the plane, we go to `index+0`.

Note that planes do not need to fully enclose a cell.

### Example from `r1/maps/mp_angel_city.bsp`

Walking the tree (in `node.child+1` direction) until we find a cell:

```python
>>> node = bsp.CELL_BSP_NODES[0]
>>> path = [node]
>>> while node.plane != -1:
...     node = bsp.CELL_BSP_NODES[node.child + 1]  # all behind
...     path.append(node)
>>> path
[<CellBSPNode (plane:  22, child:    1)>,
 <CellBSPNode (plane:   1, child: 1771)>,
 <CellBSPNode (plane: 174, child: 1825)>,
 <CellBSPNode (plane: 156, child: 2569)>,
 <CellBSPNode (plane:  38, child: 2777)>,
 <CellBSPNode (plane:  41, child: 3019)>,
 <CellBSPNode (plane:  -1, child:   62)>]
```

Taking a detour at the 2nd last branch:

```python
>>> bsp.CELL_BSP_NODES[3019]  # child+0
<CellBSPNode (plane: 4, child: 3021)>
>>> bsp.CELL_BSP_NODES[3022]  # child+1
<CellBSPNode (plane: -1, child: 71)>
>>> bsp.CELLS[71]
Cell(num_portals=14, first_portal=892, flags=<CellSkyFlags.UNKNOWN_2: 1>, leaf_water_data=-1)
>>> {p.plane for p in bsp.PORTALS[892:][:14]}
{1, 4, 41}  # portals lie on planes we walked to get here
```

Exporting to a `.obj` model so we can visualise this in 3D:

```python
>>> from bsp_tool.utils.geometry import Vertex, Polygon, Mesh, Model, Material
>>> models = {"cell_71": cell_71_aabb.as_model()}  # purple
>>> models.update({  # wireframes inside purple bounds
...     f"portal_{i:03d}": Model(meshes=[bsp.portal_mesh(i)])
...     for i in range(892, 892 + 14 + 1)})
>>> models.update({  # red & blue
...     f"plane_{i:03d}": Model(meshes=[
...         Mesh(Material("plane"), [Polygon([
...             Vertex(pos, plane(i).normal)
...             for pos in plane(i).as_triangle()])])])
...     for i in (22, 1, 174, 156, 38, 41, 4)})
>>> bsp_tool.scene.Obj.from_models(models).save_as("mp_angel_city.cell_71.obj")
```
