This is slightly incorrect & resulted in very messy `.prt` files

`PortalEdgeRefs -> PortalEdges` is correct
`PortalEdges -> PortalVertexReferences` definitely isn't

All that really matters for making a `.prt` is:
```
Portal -> PortalVertexReference -> PortalVertex
      \-> Cell
```

`Portal -> PortalEdgeReference -> PortalEdge` is also indexed w/ the same `.first_ref` & `.num_refs` members
But `PortalVertexRefs -> PortalVerts` gives nice clean quads

All other portal lumps are just tables of `Vertex-Edge` relationships
Which must be incredibly useful to the game engine, but are difficult to visualise.
Each lump (`PortalVertexEdges` & `PortalEdgeIntersect*`) can be used to calculate the other.
Respawn likely keeps multiple precalculated tables because lookups are faster.
