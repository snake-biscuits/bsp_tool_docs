`CellBspNode` only has a `plane` & `child` index (1 of each)
When `plane == -1`: `child` indexes `Cells`

```python
>>> bsp.CELL_BSP_NODES[0]
<CellBSPNode (plane: 18, child: 1)>
>>> bsp.CELL_BSP_NODES[1]
<CellBSPNode (plane: 15, child: 3)>
>>> bsp.CELL_BSP_NODES[3]
<CellBSPNode (plane: 14, child: 5)>
>>> bsp.CELL_BSP_NODES[5]
<CellBSPNode (plane: -1, child: 3)>  # not a CellBspNode
```
```python
>>> x = sorted({n.child for i, n in enumerate(bsp.CELL_BSP_NODES) if n.plane == -1})
>>> len(x)
74
>>> min(x), max(x)
(0, 73)
bsp.CELLS
<BspLump(74 Cell) at 0x000001D5D674F890>
```
