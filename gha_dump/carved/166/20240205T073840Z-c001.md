# `WaveData`
1024x1024 RGBA 32-bit texture
Only the Blue & Green channels of the texture have data, the rest are blank

## Extraction
```python
>>> from PIL import Image
>>> with open("maps/mp_rr_tropic_island_mu2.bsp.0030.bsp_lump", "rb") as raw_file:
...     Image.frombytes("RGBA", (1024, 1024), raw_file.read(), "raw").save("storm_point.wave_data.raw.tga")
```
Alpha channel will need to be inverted / disabled, otherwise the image will appear invisible
If you save as `.png` transparent pixels' colour will be deleted.
