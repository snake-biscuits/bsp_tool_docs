```asm
cmp     r9 , rcx
jz      valid_lump_size
```
This checks `r9 == rcx`, `jz` jumps past the call to the error function (`if(False) { Error("...") } /* go here */`)
`r9` holds the original lump size, while `rcx` holds the largest valid lump size less than `r9`
The fancy integer division trick the compiler is doing here also stores the remainder in a register, very neat
