### Misc
 * Each face includes a single texel (4 bytes) before each "texture"
   - Seems to be the average colour (including exponent)
   - In `cso2_2018` this texel is always `00 00 00 00`
   - Haven't confirmed if faces without lightmaps generate these
 * Lightmap UVs have a boundary of half a texel
   - To extract the image for a given face, you have to add 1 to the size of each axis
   - Does VRAD sample this texel, instead of bleeding the rest of the lightmap?
