## Source Engine Format
Source Engine's Lighting lump is very similar to Quake / Quake 2's

Rather than a full image, `LIGHTING` lumps pack a series of texels for each `Face` w/ offsets & sizes
Lightmap Pages can be assembled at runtime to save on video memory

> **TODO**: Source Engine console commands for showing lightmaps & pages

The Orange Box introduced HDR lighting
Dynamic Range is achieved by storing an "Exponent" value in the Alpha channel of each RGBA lightmap texel
The lightmap page appears to be modified at runtime to match the current exponent

> **NOTE**: https://github.com/magcius/noclip.website seems to show HDR pretty well
> It's probably some complex system based on leaves & `tonemap_controller` entities
