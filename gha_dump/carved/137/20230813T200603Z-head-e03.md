Doing some bash script trickery to eliminate duplicate files
SHA256 hashes will be dumped into the same file w/ `sha256sum`

```bash
$ cd /mnt/e/Mod/ApexLegends/seasonX/DDmmmYY/
$ find -type f -name "*.bsp" -o -name "*.ent" -o -name "*.bsp_lump" -exec sha256sum -b {} \; | tee hashes.sha256
```
Where `seasonX/DDmmYY` is a release (e.g. `season0/4feb19`)

I could do separate files to use `sha256sum -c`
But since everything is getting hashes I'll compare the hashes w/ python

Once duplicates have been identified I'll turn them into symlinks (`mklink` on Windows)
