>2017 - May: The Titanfall 2 single-player only [Icepick](https://titanfallmods.com/) mod launcher enters development

Icepick is significant because it served as a base / inspiration for Northstar
The Icepick devs also managed to create a python script for converting Titanfall 2 `.bsp` files into `.obj` models
Likely reversed from a function present in Titanfall 2 itself, this code formed the bedrock of `bsp_tool` research into Titanfall 2 maps
